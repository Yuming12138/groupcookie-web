### SECTION 5 — Scoring Rationale

**F1 — Thermodynamic stability.**  
The target has E_hull = 0.0000 eV/atom, so it is predicted to be a ground-state phase and receives 98/100. TS analogues include several 0 eV/atom thallium-containing compounds and fluorides, supporting that related chemistries can be thermodynamically stable (TS1, TS4, TS5). CS is contradictory or weak for this factor because the chemically similar oxide set includes both stable and highly metastable Pt/Bi oxides, so CS is treated as insufficient evidence and neutral (50). The remaining uncertainty is whether the computed TlF-II-like Pbcm structure is the experimentally accessible ambient polymorph or requires specific crystallization history [Reasonable Inference].

**F2/F3 — Route 1, aqueous cooling crystallization.**  
Severity is low because SS2 uses only hot aqueous solution and cooling, and TS4 uses 100 °C aqueous precipitation/heating; the main deductions are multiple handling steps and toxic Tl salts. Kinetics are favorable because dissolved ions bypass solid-state diffusion, and SS2 demonstrates crystallization of a 2D fluoride sheet compound from solution. The uncertainty is phase selectivity: SS2 crystals were small, and TS4 notes single-crystal growth attempts can be difficult for thallium compounds.

**F2/F3 — Route 2, solvothermal crystallization.**  
Severity remains moderate because SS4/TS3 use 150 °C sealed Teflon-lined autoclaves, while TS5 uses 230 °C hydrothermal conditions; these are not extreme pressures or temperatures. Kinetics are favorable because solvothermal media promote dissolution/reprecipitation, and both SS4/TS3 and TS5 produced crystalline fluoride/thallium-containing products. The main uncertainty is competing phase formation, since SS4/TS3 report byproducts for some ASnF₃ compositions and moisture sensitivity for CsSnF₃.

**F2/F3 — Route 3, sealed-ampoule melt growth.**  
Severity is higher because SS5 uses sealed ampoules and long annealing, while SS3/TS2 show Tl compounds may require Ar/vacuum and protected crucibles. Kinetics are good in the melt because precursor and product are compositionally identical TlF [Reasonable Inference], but ordering/polymorph selection may be slow; SS5 required one month and SS3/TS2 required 14 days. The key uncertainty is container compatibility and volatile TlF redistribution in a sealed thermal gradient [Reasonable Inference].

**F2/F3 — Route 4, direct fluorination.**  
Severity is high because SS1/TS1 require F₂ gas, pressure fluorination at 350–400 atm, pre-fluorination to avoid explosions, and Au-tube annealing. Kinetics are adequate because F₂ is highly reactive, but full conversion from Tl metal/oxide/carbonate to ordered TlF requires substantial reconstruction [Reasonable Inference]. This route is plausible but not preferred because it is far more hazardous than required for a simple binary TlF target [Reasonable Inference].

**F4 — Amorphization tendency.**  
The target has only one cation type and a simple equivalent Tl–F 4-coordinate sheet, so the ionic-radius-difference and mixed-polyhedral-connectivity checks are not triggered [Target description]. The unit cell appears simple from the one Tl/F site description, though the exact atom count is not provided, so this is a low-risk but not zero-uncertainty assessment [Target description].
