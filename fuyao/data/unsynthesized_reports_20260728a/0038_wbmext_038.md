### SECTION 5 — Scoring Rationale

**F1 — Thermodynamic Stability.**  
The supplied target E_hull is 0.000 eV/atom, which places it in the highest thermodynamic score bin. (Target data) Close Pb-oxide analogues in CS/SS/TS are also reported at or near hull, including SrPbO3, SrBiO3, NaBiO3, Ca2PbO4, and BaPbO3 polymorphs. (CS2, CS3, CS4, SS1, SS4, TS1, TS3, TS4) Remaining uncertainty is experimental, because the target is theory-only and CS/SS/TS do not prove this exact ilmenite CaPbO3 polymorph has been synthesized. (Target data; CS1, SS2, CS4)

**F2/F3 — Route 1.**  
Route 1 is severe because it requires GPa pressure, capsule work, Pb oxides, and a multistep precursor/capsule workflow, but it has the best target-composition evidence. (CS1, SS2) Kinetics are comparatively favorable because same-composition CaPbO3 forms in 1–3 h at 900–1200 °C, but structural reconstruction is penalized because the reported analogue is Pnma perovskite rather than R-3 ilmenite. (CS1, SS2; Target data) **Insufficient evidence from TS for same-composition HPHT CaPbO3 synthesis; TS source signal neutral = 50.**

**F2/F3 — Route 2.**  
Route 2 has lower thermal severity than Route 1 if the SrPbO3-style 450 °C high-pO2 route transfers, but high-pressure O2 remains a controlled-atmosphere hazard. (CS2, SS1, TS1) Kinetics are uncertain because high-pO2 stabilizes Pb(IV) oxides, yet no CS/SS/TS example shows CaPbO3 ilmenite forming directly under these conditions. (CS2, SS1, TS1, TS4; Target data) The route is therefore plausible for oxidation control but weaker for polymorph control. (CS2, TS4; Target data)

**F2/F3 — Route 3.**  
Ambient ceramic synthesis is operationally accessible and supported for BaPbO3 analogues, but repeated sintering/regrinding and Pb oxide loss control reduce its score. (SS3, SS5, TS2, TS5) Kinetics are slower because dry solid-state routes require long thermal cycles, and structural selectivity is weak because same-composition CaPbO3 evidence points to HP synthesis. (CS1, SS2, SS5, TS5) **Insufficient evidence from CS for ambient-pressure CaPbO3 synthesis; CS source signal neutral = 50.**

**F2/F3 — Route 4.**  
Flux synthesis improves precursor activity and mass transport because Ca2PbO4 crystals can be obtained from CaCO3/PbO/CaCl2 at 800 °C. (SS4, TS3) The route is penalized strongly for structural reconstruction because the demonstrated flux product is Ca2PbO4, not CaPbO3 ilmenite, so it is best viewed as a precursor-conditioning route. (SS4, TS3, CS1, SS2; Target data) **Insufficient evidence from CS for direct flux synthesis of target CaPbO3; CS source signal neutral = 50.**

**F4 — Amorphization Tendency.**  
The target has mixed corner/edge/face-sharing connectivity, and the ilmenite NaBiO3 analogue shows the same style of mixed polyhedral sharing. (CS4; Target data) The Ca2+/Pb4+ size contrast likely triggers the radius-mismatch check [Reasonable Inference], while exact atom count is not provided by CS/SS/TS and is treated as non-triggering but uncertain. **Insufficient evidence from CS/SS/TS for exact target unit-cell atom count; source signal neutral = 50 for C2.**
